# letool Module Production Readiness

## Status Legend

| Status | Meaning |
|---|---|
| stable-toolkit | Pure utility or well-tested internal framework code. |
| beta-starter | Usable starter, but still needs more combination and integration tests. |
| mock-only | Development/test mock implementation, not production external-service integration. |
| official-sdk | 通过厂商官方 SDK 执行真实外部操作，仍需实际账号契约测试。 |
| framework-adapter | 基于成熟框架提供便利门面，生产语义由底层框架和业务配置共同决定。 |
| integration-needed | Real external dependency exists conceptually, but production controls or contract tests are incomplete. |

| Javadoc baseline | 发布 profile 使用 `doclint=none` 生成 Central 所需 Javadoc 制品；严格 DocLint 仍按模块治理，不把历史注释格式问题伪装成 API 行为错误。 |
